# 量子重ね合わせチェス (GitHub Pages)

ブラウザだけで遊べる「量子重ね合わせチェス」です。ルール判定も思考エンジンも Rust → WebAssembly で動きます。

https://volatilerye.github.io/quantum-superposition-chess/

## ルール (通常のチェスとの違い)

- 初期配置の駒はすべて、ポーン・ナイト・ビショップ・ルーク・クイーン・キングの重ね合わせ
- 駒は重ね合わせのどれか 1 種類として動き、動いた後はその動きと矛盾する種類が除外される
  (例: ナイトの跳び方をしたらナイトに確定、e2-e4 ならポーン・ルーク・クイーンのいずれか)
- 各色の駒は初期配置の駒数 (P8 N2 B2 R2 Q1 K1) に割り当てられなければならず、
  どの割り当てでもありえない種類は動いていない駒・取られた駒からも除外される
  (成った駒は元の役割がポーンとして数える)
- チェック: 自分の盤上のキング候補が 1 枚だけのとき、その駒が利かされていればチェック (確定していなくてもよい。
  「利き」は相手の駒のありうる種類すべてで判定)。チェックを残す手・チェックされにいく手は指せず、
  チェックを外せなければチェックメイトで負け。
  自分の手で自分の盤上の駒のどれもキングでありえなくなったら (= 取られた駒がキングだったと確定させたら)、
  その手を指した時点で負け (棋譜では `†`)
- 対消滅: 1 手で両者とも盤上の駒のどれもキングでありえなくなったら引き分け (棋譜では `∅`)
- キャスリング: 同じ段にある未移動のキング候補と未移動のルーク候補で、間に駒がなく 2 マス以上空いていれば可
  (キング候補がチェックされておらず、またぐマス・行き先が利かされていないこと)。キングはルークの方へ 2 マス、
  ルークはキングがまたいだマスへ動き、それぞれキングとルークに確定
- アンパッサン: 直前にポーンとして 2 マス進めた駒をポーンとして取る。取った駒・取られた駒ともポーンに確定
- ポーンとしての 2 マス前進は、まだ動いていない駒なら 2 段目だけでなく 1 段目からもできる (1 段目→3 段目。黒は 8 段目→6 段目)
- ポーンとして最終段に入る手は成り。同じマスへの「ポーン以外としての移動」とは別の手として選べる
