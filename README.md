# 量子重ね合わせチェス (GitHub Pages)

ブラウザだけで遊べる「量子重ね合わせチェス」です。ルール判定も思考エンジンも Rust → WebAssembly で動きます。

https://volatilerye.github.io/quantum-superposition-chess/

## ルール (通常のチェスとの違い)

- **初期配置**
  - すべての駒が、ポーン・ナイト・ビショップ・ルーク・クイーン・キングの重ね合わせ
  - 「初期配置」の設定で、どちらかの色 (または両方) を通常のチェスの配置から始めることもできる
- **動きと重ね合わせ**
  - 駒は重ね合わせのどれか 1 種類として動き、動いた後はその動きと矛盾する種類が除外される
    (例: ナイトの跳び方をしたらナイトに確定、e2-e4 ならポーン・ルーク・クイーンのいずれか)
  - 各色の駒は通常の駒数 (P8 N2 B2 R2 Q1 K1) に割り当てられなければならない (成った駒はポーンとして数える)
  - どの割り当てでもありえない種類は、動いていない駒・取られた駒からも除外される
- **チェックと勝敗**
  - チェック: 自分の盤上のキング候補が 1 枚だけのとき、その駒が利かされている状態 (キングに確定していなくてもよい)
  - 「利き」は相手の駒のありうる種類すべてで判定する
  - チェックを残す手・チェックされにいく手は指せない。チェックを外せなければチェックメイトで負け
  - 自分の手で自分の盤上の駒のどれもキングでありえなくなったら (= 取られた駒がキングだったと確定させたら)、
    その手を指した時点で負け (棋譜では `†`)
  - 対消滅: 1 手で両者とも盤上の駒のどれもキングでありえなくなったら引き分け (棋譜では `∅`)
- **キャスリング**
  - 同じ段にある、未移動のキング候補と未移動のルーク候補で指せる
  - 間に駒がなく、2 マス以上空いていること
  - キング候補がチェックされておらず、またぐマス・行き先が利かされていないこと
  - キングはルークの方へ 2 マス、ルークはキングがまたいだマスへ動き、それぞれキングとルークに確定
- **ポーンとしての動き**
  - 未移動の駒は、2 段目だけでなく 1 段目からもポーンとして 2 マス前進できる (1 段目→3 段目。黒は 8 段目→6 段目)
  - アンパッサン: 直前にポーンとして 2 マス進めた駒をポーンとして取る。取った駒・取られた駒ともポーンに確定
  - ポーンとして最終段に入る手は成り。同じマスへの「ポーン以外としての移動」とは別の手として選べる

## オンライン対戦

「相手」で「対人（オンライン）」を選んで「対局開始」を押すと、接続のダイアログが開きます。

1. 招待する側が「招待リンクを作る」を押し、招待リンクをチャットなどで相手に送る
2. 相手が招待リンクを開くと返信リンクができるので、招待した側に送り返す (送ったらすぐページに戻って開いたままにする)
3. 招待した側が返信リンクを同じブラウザで開くと、招待を作ったタブに自動で受け渡されて対局が始まる
   (手番・初期配置は招待した側の設定)

仲介サーバーは使わず、ブラウザ同士を WebRTC で直接つなぎます (`web/online.js`)。
接続情報はリンクの `#join=` / `#reply=` に入れ、返信リンクを開いたタブから招待を作ったタブへは BroadcastChannel で渡します。
自分の外向きアドレスを調べるために Google の公開 STUN サーバーだけを使い、手の内容は STUN には送りません。
TURN サーバーは使わないので、ネットワークによってはつながらないことがあります。
スマホでブラウザが裏に回ると通信が止まるので、そのあいだは「接続が不安定です」と表示して相手が戻るのを待ちます。
